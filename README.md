# Tree-Based Machine Learning

A step-by-step study of decision trees and tree ensembles through theory,
paper exercises, quizzes, and practical implementations.

## Study approach

For each lesson:

1. Understand the theory.
2. Solve examples on paper.
3. Complete the quiz.
4. Implement the algorithm using native Python.
5. Use Python libraries and compare results.
6. Explore a C++ implementation.

## Topics

Decision trees, bagging, Random Forests, Extra-Trees, AdaBoost,
gradient boosting, XGBoost, LightGBM, CatBoost, and model evaluation.
